## 2. Content issues found

Things to fix or confirm before launch:

- **Wrong roadmap text on MERN and Python pages.** Roadmap step descriptions are looked up by step name only, so shared names show Salesforce wording: MERN → *JavaScript, Testing, Real Project*; Python → *Testing, Automation, Real Project* (e.g. Python "Testing" says "Write meaningful Apex tests and LWC Jest tests").
- **Generic filler on most non-Salesforce roadmap steps.** MERN (9 steps), UI/UX (all 10), Python (8) all show the same sentence: "Guided practice, hands-on assignments and mentor feedback."
- **Placeholder module topics (Python).** Modules *Automation* and *Capstone* list only "Practical exercises / Guided implementation / Project application".
- **Demo contact details.** Email (hello@example.com) and address (123 Example Street) are placeholders; the site itself labels them as demo.
- **Empty pages.** *Our mentors* and *Learner stories* have no real mentor profiles or testimonials yet (the API returns empty lists) — the pages show explanatory text only.
- **Fees, batch dates and certificates are not stated anywhere** — every mention says to speak with the team.
- **Brand vs domain.** Everything visible says CloudLight Solutions, but the domain, repo and database are still named cloudbytelabs.
- **Services vs content.** The services band lists consulting, ERP, ecommerce and integrations, but there are no pages describing those services yet.
